# Fitvia — Fitness & Gym WordPress Theme

A high-energy Full Site Editing (block) theme for gyms, fitness studios and personal trainers.

## Design

- Near-black (`#0d0d0f`) + electric volt green (`#d4ff3f`)
- Free-trial hero with pulsing badge
- Class cards, trainer profiles, weekly schedule table
- Inter typeface (bundled, OFL licensed)
- "Midnight" and "Daybreak" style variations included

## Templates

| Template | Purpose |
|---|---|
| `front-page.html` | Hero, trust badges, classes, stats, trainers, transformations, gallery, trial CTA |
| `page-classes.html` | Class grid + weekly schedule + trial CTA |
| `page-trainers.html` | Trainer profiles + about story + trial CTA |
| `page-membership.html` | Pricing plans + FAQ + trial CTA |
| `page-schedule.html` | Schedule table + class grid + trial CTA |
| `page-contact.html` | Contact info + gallery + trial CTA |
| `page.html` / `page-wide.html` | Standard and wide page layouts |
| `single.html`, `archive.html`, `search.html`, `index.html`, `404.html` | Blog and utility templates |

## Block patterns (13)

`hero-cta`, `trust-badges`, `classes-grid`, `trainers`, `schedule-table`, `pricing-plans`, `testimonials`, `stats-band`, `faq`, `about-story`, `gallery`, `contact-info`, `cta-trial`
