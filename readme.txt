== Description ==

Fitvia is a high-energy Full Site Editing theme built for gyms, fitness studios and personal trainers. Near-black canvas with electric volt-green accents, a trial-offer hero, trust badges, class grid, certified trainers, weekly schedule table, membership pricing, animated stats, transformations, FAQ, about story, photo gallery and a free-trial CTA — everything a fitness brand needs to fill classes and sell memberships.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates, curated block patterns, and "Midnight" and "Daybreak" style variations. Translation-ready and accessibility-conscious.
